# 实施路线图

路线图描述建议方向，不代表已经实现或承诺的交付日期。

## 阶段 0：文档基线（已完成）

- [x] 项目定位与边界
- [x] 文档导航
- [x] 标准研究方法
- [x] 数据与指标口径
- [x] 单股报告模板
- [x] 风险与合规说明

## 阶段 1：仓库工程化

- [ ] 选择许可证并补充贡献指南
- [ ] 建立 `src/`、`tests/`、`data/` 和 `reports/`
- [ ] 定义配置格式、日志格式与版本策略
- [ ] 配置格式检查、单元测试和持续集成
- [ ] 建立示例数据，确保测试不依赖在线服务

完成标准：全新环境可按说明完成安装，基础测试可重复通过。

## 阶段 2：数据层

- [ ] 定义统一的证券、交易日、价格和财务字段模型
- [ ] 接入至少一个行情源和一个法定披露来源
- [ ] 实现缓存、重试、限流和来源记录
- [ ] 处理复权、币种、时区、缺失值和重复数据
- [ ] 增加数据新鲜度与质量检查

完成标准：任一派生指标都能追溯到原始数据、时间与计算版本。

## 阶段 3：分析引擎

- [ ] 财务趋势和质量指标
- [ ] 相对估值与 DCF 情景
- [ ] 收益、波动、回撤和相对表现
- [ ] 催化剂、风险和证据清单
- [ ] Markdown/JSON 结构化输出

完成标准：固定输入产生确定输出，公式有单元测试和边界测试。

## 阶段 4：报告与复盘

- [ ] 根据模板生成可审阅报告
- [ ] 保存分析时点、数据快照和假设
- [ ] 支持财报更新前后差异比较
- [ ] 建立研究命题、观察条件和复盘日志
- [ ] 统计预测偏差与方法稳定性

完成标准：历史报告保持可复现，后续信息不会无痕覆盖原判断。

## 阶段 5：扩展能力

- [ ] 多市场、多币种和不同会计准则
- [ ] 行业专用指标插件
- [ ] 组合暴露和相关性分析
- [ ] 可视化与只读仪表盘
- [ ] 权限、审计和更细粒度的数据许可控制

## 非目标

除非未来明确调整范围，本项目不计划：

- 代用户保管资金或证券；
- 默认连接真实账户自动下单；
- 将单一评分直接转换为交易；
- 以不可解释模型替代证据和假设；
- 把第三方数据重新发布为开放数据集。

## 优先级原则

1. 正确性与可追溯性；
2. 时间边界与风险控制；
3. 测试与可复现性；
4. 易用性；
5. 性能与功能数量。
