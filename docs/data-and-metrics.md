# 数据与指标

## 数据时间边界

每份报告必须明确：

- **分析时点**：做出判断的具体日期和时区；
- **数据截止日**：价格、财务和宏观数据各自的截止时间；
- **发布日期**：数据何时对市场可见；
- **报告期**：数据描述的业务期间。

回测与历史复盘只能使用当时已经发布的数据。财报期末日不等于发布日期。

## 数据分层

建议按以下层级保存数据：

- Raw：来源原样数据，不覆盖、不手工改写；
- Normalized：统一日期、币种、单位、复权和字段名称；
- Derived：由明确公式计算的指标；
- Output：图表、表格和报告。

每次派生计算应记录输入版本、计算时间和异常处理方法。

## 财务指标

### 增长

```text
同比增长率 = 本期值 / 上年同期值 - 1
复合年增长率 = (期末值 / 期初值)^(1 / 年数) - 1
```

当期初值为负数或接近零时，不应使用普通增长率描述，应同时给出绝对变化。

### 盈利能力

```text
毛利率 = 毛利润 / 营业收入
营业利润率 = 营业利润 / 营业收入
净利率 = 归母净利润 / 营业收入
ROE = 归母净利润 / 平均股东权益
ROIC = 税后经营利润 / 平均投入资本
```

跨公司比较前必须统一会计口径，并解释重大非经常项目。

### 现金流与杠杆

```text
自由现金流 = 经营活动现金流 - 资本性支出
净负债 = 有息负债 - 现金及现金等价物
净负债 / EBITDA = 净负债 / EBITDA
利息覆盖倍数 = EBIT / 利息费用
```

金融机构不宜机械套用普通企业的净负债指标。

## 市场指标

### 收益率

默认采用复权收盘价：

```text
简单收益率 = P_t / P_(t-1) - 1
区间收益率 = P_end / P_start - 1
```

必须说明分红、拆股和币种换算是否已处理。

### 波动与回撤

```text
年化波动率 = 日收益率标准差 × sqrt(年交易日数)
回撤 = 当前净值 / 历史峰值 - 1
最大回撤 = 观察期内回撤的最小值
```

年交易日数应按市场设置，不能盲目固定为 252。

### 相对表现

```text
相对收益 = 标的区间收益 - 基准区间收益
```

Alpha、Beta、Sharpe 等指标必须同时披露区间、频率、无风险利率和样本量。

## 估值指标

```text
市盈率 = 股价 / 每股收益
市净率 = 市值 / 归母股东权益
EV = 市值 + 有息负债 + 少数股东权益 - 现金
EV/EBITDA = 企业价值 / EBITDA
自由现金流收益率 = 自由现金流 / 市值
```

负盈利、一次性收益、周期峰值利润会使倍数失真，应改用更合适的口径或标记为不适用。

## 数据质量检查

发布前至少检查：

- 标的与交易所映射是否正确；
- 时区、交易日和财报发布日期是否正确；
- 币种、单位和千/百万/十亿转换是否一致；
- 价格是否复权，市值与股本日期是否匹配；
- 缺失值是否被误填为零；
- 同比是否对齐相同季度；
- TTM 是否包含完整四个季度且无重复；
- 关键数字是否能在来源中复核；
- 异常值是否保留说明而非静默删除。
