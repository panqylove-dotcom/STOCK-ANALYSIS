# 研究方法

## 1. 定义问题

开始前记录：

- 标的代码、交易所、证券类型和币种；
- 研究目的：初筛、深度研究、财报更新、估值更新或持仓复盘；
- 分析日期、数据截止时间与目标持有周期；
- 对照基准、行业或可比公司；
- 已知约束，例如流动性、市场准入和风险预算。

问题应可验证，例如：“未来四个季度的利润率改善能否抵消估值收缩风险？”

## 2. 建立证据账本

关键材料至少记录标题、发布者、发布日期、访问日期、链接和用途。来源优先级通常为：

1. 监管披露、交易所公告、公司法定报告；
2. 公司投资者关系材料与业绩电话会；
3. 政府、央行、统计机构及行业组织；
4. 可靠的数据供应商；
5. 新闻与第三方研究；
6. 社交媒体，只作为线索或情绪观察，不作为核心事实的唯一来源。

同一关键数字出现冲突时，保留冲突记录并说明最终采用依据。

## 3. 基本面分析

### 商业质量

- 收入来源、客户结构、地域分布和周期敏感度；
- 定价权、切换成本、网络效应、品牌或规模优势；
- 资本密集度、营运资本需求和再投资回报；
- 管理层资本配置、股权激励和治理结构。

### 财务质量

至少观察 3–5 年和最近季度趋势：

- 收入、毛利率、营业利润率、净利润；
- 经营现金流、资本开支和自由现金流；
- 净负债、利息覆盖、债务期限；
- 股份稀释、回购、分红和一次性项目。

不要仅根据单季变化推断长期趋势；季节性行业必须采用同比或滚动口径。

## 4. 估值

根据商业模式选择方法：

- 稳定盈利企业：P/E、EV/EBIT、自由现金流收益率；
- 高增长或尚未稳定盈利企业：EV/Sales，并结合毛利率与增长质量；
- 金融机构：P/B、ROE、资本充足率和资产质量；
- 资产型企业：NAV、重置成本或周期中枢盈利；
- 可预测现金流企业：DCF，公开收入增长、利润率、税率、再投资、折现率和终值假设。

估值输出优先使用区间而非单点，并做关键变量敏感性分析。

## 5. 市场与技术面

技术指标用于描述价格行为，不替代基本面判断。可观察：

- 相对 20/50/200 日均线的位置与斜率；
- 1/3/6/12 个月收益和相对基准表现；
- 实现波动率、最大回撤、成交量和跳空；
- 支撑、阻力只作为行为区间，不当作确定性价格。

任何回测必须控制幸存者偏差、前视偏差、样本外验证、交易成本和流动性。

## 6. 催化剂与风险

催化剂应有时间窗和可观测结果，例如财报、产品发布、审批、产能投放或资本配置事件。

每项风险至少记录：

- 风险事件；
- 发生概率的定性等级；
- 影响范围；
- 可提前观察的指标；
- 缓释因素；
- 导致投资命题失效的阈值。

## 7. 情景与结论

至少建立悲观、基准、乐观三个情景。每个情景使用一致的收入、利润率、估值和时间假设，避免只改变目标价。

结论采用条件式表达：

- 当前证据支持什么；
- 哪些条件尚未满足；
- 什么变化会提高或降低置信度；
- 下次复盘日期与触发事件。

## 8. 可选评分框架

评分不是事实，仅用于保持研究一致性。可按 1–5 分记录：

| 维度 | 参考问题 |
| --- | --- |
| 商业质量 | 护城河、可预测性和资本回报如何？ |
| 财务质量 | 增长、利润、现金流与资产负债表是否健康？ |
| 估值 | 当前价格是否为合理假设留下安全边际？ |
| 动量与市场结构 | 趋势、波动与流动性是否支持观察周期？ |
| 风险 | 下行事件是否可识别、可承受、可监控？ |
| 证据质量 | 关键结论是否由及时、可靠来源支持？ |

不得将总分机械转换为交易指令。
